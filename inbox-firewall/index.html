What actually keeps

The short version: not the confidence score. Below is the argument in four paragraphs, and then a lab where you can pull each defense out and watch the numbers move.

The study

One question, answered with numbers: how small can a model get before local automation stops being safe?

A ~26M router — about a thousandth the size of a frontier model — turns each inbox message into one line of a closed, typed action DSL. A hand-written validator parses it, never eval; a tier policy decides what may auto-execute; and anything ambiguous, hostile, or malformed escalates instead of acting. The safety boundary lives in the validator and policy, not in the model.

The headline is the one I didn't expect. The keyword baseline is strong — 88.1% action accuracy at 74.8% coverage — but it confidently acts on 11 messages it should have escalated, and every one of them is a valid action the validator is powerless against. Held-out calibration then drove ECE to 0.000 and moved that count by exactly zero: confidence carries no signal about an adversary it never saw at calibration time. What did move it was a deterministic content-trust layer that treats the message body as untrusted — unsafe 11 → 7, for about two points of coverage. Calibration is a coverage instrument, not a safety one.

Reported plainly, because it is the honest part: the remaining 7 are phishing and social engineering — a different threat needing a different layer, and unsafe → 0 is genuinely hard. The 26M fine-tune is deferred, not done — the training exporter is built and verified, but this machine has no training runtime, and I won't quote a number I haven't measured. The whole thing was built collaboratively in Council, a terminal chat where Claude Code and Codex work the same repo alongside me.

    The result

    Confidence is a coverage instrument, not a safety boundary.

    Typed outputs catch malformed actions. Content-trust checks catch obvious injections. Phishing remains. The honest system escalates what its deterministic layers cannot prove safe.
